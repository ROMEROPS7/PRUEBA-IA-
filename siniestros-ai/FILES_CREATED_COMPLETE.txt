================================================================================
KEY ORCHESTRATION ENDPOINT
================================================================================

POST /api/siniestros

This is the KEY endpoint that orchestrates the entire claim workflow:

FLOW:
1. Receive claim creation request with:
   - cliente_id
   - poliza_id
   - canal (web, whatsapp, email, phone, oficina)
   - descripcion
   - prioridad_sugerida (optional)

2. Create siniestro record in system
   - Generate unique SIN-YYYY-NNNNNN number
   - Set initial estado = "abierto"
   - Set initial timeline entry

3. Call ORCHESTRATOR AGENT to coordinate:
   - Documents analysis agent (type detection, OCR, validation)
   - Chat agent (NLP, intent extraction, context understanding)
   - Voice agent (if voice channel, sentiment analysis)
   - Assignment agent (load balancing, expertise matching)

4. Broadcast WebSocket Events:
   - Send "new_siniestro" to all connected gestores
   - Send to all connected admins
   - Real-time updates to client if connected

5. Notify Participants:
   - Send SMS/Email to gestor if high priority
   - Send WhatsApp/SMS to client confirming receipt

6. Return Complete Response:
   - Full siniestro object
   - Timeline with creation entry
   - Ready for immediate updates
