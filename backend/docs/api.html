SiniestrosAI API

API REST completa para la plataforma de gestion inteligente de siniestros con agentes IA.

Base URL: http://localhost:3001/api

Caracteristicas principales

  • Gestion completa de siniestros (CRUD)
  • Sistema anti-fraude con scoring multidimensional
  • Agente IA para clasificacion, resumen y chat
  • Metricas y analytics en tiempo real
  • Integracion WhatsApp y voz via Twilio
  • WebSockets para actualizaciones en tiempo real
  • Gestion de clientes, peritos y agentes

Formato de respuesta

Todas las respuestas son JSON. Los errores devuelven {"error": "mensaje"}.

Autenticacion

La API utiliza JWT (JSON Web Tokens) para autenticacion. Existen tres niveles de acceso:

NivelDescripcionEjemplo
PublicoNo requiere autenticacionHealth check
OpcionalToken opcional, funciona sin elListar siniestros
RequeridoToken obligatorio en headerEliminar siniestro

Obtener Token

Realiza login en POST /api/auth/login para obtener un JWT.

Usar Token

Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

API Keys

Para integraciones servidor-a-servidor, se puede usar una API Key en lugar de JWT:

X-API-Key: sai_live_xxxxxxxxxxxxxxxxxxxx
Importante: Las API Keys se generan desde el panel de administracion y tienen los mismos permisos que el usuario que las crea.

Roles

RolPermisos
adminAcceso total: crear, leer, actualizar, eliminar todo
gestorCRUD siniestros y clientes, no puede eliminar ni acceder a admin
peritoVer y actualizar siniestros asignados

Rate Limiting

La API implementa limites de tasa para proteger contra abuso:

TipoLimiteVentana
General100 requests15 minutos
Auth (login)10 requests15 minutos
Upload20 requests15 minutos
IA endpoints30 requests15 minutos

Los headers de respuesta incluyen:

X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1703001200
429 Too Many Requests: Se devuelve cuando se excede el limite. Espera el tiempo indicado en Retry-After.

Versionado

VersionEstadoBase URL
v1Actual/api/
v2Planificada/api/v2/

Cambios planificados v2

  • GraphQL support
  • Paginacion cursor-based
  • Webhooks salientes configurables
  • API Key scopes granulares
  • Batch operations
